# PARC Metadata Schema for Environmental Chemical Monitoring Data

**Author: Katarína Řiháčková** 

**Contributors**
TBC

This repository contains a formalized metadata schema for data concerning monitoring of chemicals in the outdoor environment defined by environmental monitoring community of the European Partnership for the Assessment of Risks from Chemicals ([PARC](https://www.eu-parc.eu/)). The source for this work was the schema published in .xlsx file [published on Zenodo](https://doi.org/10.5281/zenodo.17175075). 

This schema provides a structure for reporting metadata describing a collection of environmental samples and parameters measured in these samples. This agreed set of metadata describes data concerning the occurrence of chemicals in the outdoor environment and will support their FAIRness (Findability, Accessibility, Interoperability, Reusability). The schema contains metadata elements to describe a project or monitoring programme that generated the data, contact information, elements to describe the monitoring site, sample, concentration and other parameters, and the associated codelists. Metadata elements to describe data concerning chemical occurrence in the atmospheric, terrestrial, and aquatic environments, as well as in biota, are covered.
 
The content has been thoroughly discussed over 13 workshops with domain experts held by WP7 between June and December 2024 (see list of workshops below), tested against example datasets, and later refined based on further review and consultation.
